## The problem

Language models write fluent health articles, including fluent wrong ones. The tool needed to stay
close to its sources and catch claims that weren't backed up.

## What I did

- Built a retrieval-augmented generation (RAG) pipeline: web-scraped sources, an embedding index,
  and LLaMA as the generator.
- Added a misinformation check on every generated article.
- Wrapped it in a Streamlit app and deployed it on AWS, with EC2 for the app, S3 for data and
  Lambda for scheduled content-generation jobs.
