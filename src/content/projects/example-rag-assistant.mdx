## Approach

What you built and the key decisions. Why this model, this retrieval setup, this eval?

- Chunked docs into ~400-token passages, embedded with an open embedding model.
- Hybrid retrieval (BM25 + dense), re-ranked with a cross-encoder.
- Answers must cite passages; uncited claims are dropped.
