## Built with

- [Astro](https://astro.build). Every page is plain HTML built ahead of time, with almost no
  JavaScript.
- Plain CSS. No colour on purpose: black, white, and a couple of greys.
- [IBM Plex Sans and Mono](https://www.ibm.com/plex/), self-hosted.
- The line drawings are hand-written SVG, generated from a fixed seed so they look the same on
  every build.

## Hosted on

GitHub Pages, for free. Every push to `main` is checked (formatting, lint, types, broken links),
built and published automatically.
